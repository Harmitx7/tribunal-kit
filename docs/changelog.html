v9.1.0

🌐 Autonomous Browser Intelligence & Empirical Case Law 2026-09-13
Major Milestone: Release 9.1.0 introduces a zero-dependency native browser intelligence subsystem to Tribunal Kit. Inspired by PinchTab's token-pruned CDP control, this release adds Component Synapse (reverse-engineering live DOM into React TSX + Tailwind), Empirical Case Law Bridge (codifying live audit failures into binding precedents), Runtime Sentinel (hunting dev-server error overlays), SDD Prompt Isolation (structural XML delimiter sandboxing), Super-Prompt Compiler Taxonomy Expansion, and Proxy DoS Protection.
Browser Intel Zero-Dependency Native Browser Intelligence Engine (dist/browser/)
  • Node 22 Native WebSocket CDP Engine (dist/browser/cdp.js): Zero-dependency Chrome DevTools Protocol client using Node 22 native WebSocket. Supports Page, Runtime, DOM, Accessibility, and Network domains without Playwright or Puppeteer.
  • CSRF-Protected Tab Allocation & Dynamic Ephemeral Ports (dist/browser/launcher.js): Added getFreePort() dynamic port assignment to avoid socket TIME_WAIT lockouts in concurrent test environments, alongside robust HTTP PUT /json/new tab spawning.
  • Fabel Token-Pruned Trimmer & IDPI Firewall (dist/browser/trimmer.js, idpi.js): Pure Node.js port of PinchTab's htmltrim pruning DOM to < 4,000 UTF-8 bytes. Scans scraped web content against injection vectors and isolates in <untrusted_web_content> sandboxes.
  • Proprietary Component Synapse (dist/browser/synapse.js): Reverse-engineers any live DOM element into production-ready React TSX with Tailwind CSS classes by extracting computed CSSOM properties.
  • Empirical Case Law Bridge (dist/browser/case_bridge.js): Ingests live WCAG 2.2, console, and security audit violations and codifies them into permanent binding precedents in .agent/history/case-law/.
  • Runtime Sentinel Error Hunter (dist/browser/sentinel.js): Connects to local dev servers (Next.js, Vite, CRA), parses error overlays and stack traces to locate source files, and verifies candidate fixes.
  • Five New Browser CLI Commands: Shipped tk browse, tk audit-web [--codify], tk compare-web, tk deconstruct, and tk heal.
  • Seven Native Browser MCP Tools: Registered tk_browser_navigate, tk_browser_audit, tk_browser_compare, tk_browser_screenshot, tk_deconstruct_component, tk_heal_runtime_errors, and tk_codify_browser_audit in bin/mcp-server.js.
Plugins & SDD Subagent-Driven Development Prompt Isolation & XML Delimiter Sandboxing
  • Structural XML Envelopes (.agent/templates/sdd/): Wrapped SDD prompts in <context_envelope>, <task_specification>, <diff_envelope>, and <evaluation_criteria> tags to shield AI agents against prompt injection from untrusted files and diffs.
  • Anti-Hallucination & Epistemic Protocol: Injected mandatory pre-flight constraints requiring implementers to verify every imported method or package against package.json/lockfile, mandate // VERIFY annotations, and strictly ban speculative APIs.
  • Subagent & Process Isolation: Enforced runtime process isolation banning implementers from spawning rogue subagents or self-reviewers, preserving controller-mediated wave review boundaries.
  • Machine-Readable Review Verdicts: Standardized reviewer output contract with structured JSON summaries (critical_count, important_count, minor_count) and anchored file/line citations.
2026 Runtime Super-Prompt Compiler Hardening, Impact Tier Engine & Proxy Resilience
  • Expanded Stack Taxonomy (.agent/scripts/prompt_compiler.js): Added 27 modern technologies to routing index (FastAPI, Django, GraphQL, Rust, Docker, Kubernetes, AWS, Terraform, Redis, Supabase, Playwright, Vitest, React Native, C#/.NET, SQLite, OpenTelemetry, WebGPU, LLM, RAG).
  • Governance Impact Tier Classifier (inferImpactTier): Programmatically classifies tasks into Tiers 0-3 based on action risk and domain sensitivity (auth, JWT, migrations, schema = Tier 3).
  • Adversarial Jailbreak Neutralization (sanitizeUserInput): Neutralizes bypass and override patterns (disregard previous instructions, DAN/jailbreak) into isolated <untrusted_user_input> blocks.
  • Proxy Server 413 Payload Guard (bin/proxy-server.js): Added 5MB cutoff protecting proxy interception against memory exhaustion, with clean content-length recalculation and 502 Bad Gateway handling.
  • Cross-Platform Spawning & Binary Execution (bin/spawn-agent.js, bin/wrapper.js): Native Windows shell compatibility, signal code forwarding (128 + signal), and TK_AUTO_BUILD=1 gated compilation.
Skills Corpus 185 Skills & 43 Audited Workflows
  • New Skill: browser-audit: Added dedicated browser-audit skill in .agent/skills/browser-audit/SKILL.md covering live WCAG 2.2 contrast auditing, console exception capture, and security headers.
  • New Workflows: /audit-live & /compare-web: Added live browser auditing and visual regression differ workflows in .agent/workflows/ with mandatory pre-flight loaders.
Quality & Hardening Packaging Hygiene, Self-Uninstall Guard & Dependency Pruning
  • Self-Uninstall Guard (dist/commands/uninstall.js): Added isSelfInstall check preventing accidental deletion when tk uninstall is executed within tribunal-kit itself.
  • Python Cache Purge on Prepack (scripts/clean-pycache.js): Wired clean:pycache into npm run prepack to purge __pycache__ and .pyc artifacts from published packages.
  • Dependency Pruning: Removed unused better-sqlite3 from production dependencies.
Tests & CI 482 Tests 100% Passing Across 42 Unit, 11 Integration, and 33 Rust Suites
  • Browser Unit & Integration Test Suites: Added 7 new test suites covering CSSOM-to-Tailwind mapping, runtime error hunting, prompt injection sanitization, token budgeting, and live headless navigation.
